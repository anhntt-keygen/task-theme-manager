# ⏱️ Task Theme Manager (Pomodoro Focus Timer)

Ứng dụng quản lý thời gian tập trung Pomodoro tích hợp danh sách tác vụ (To-Do List) và chế độ giao diện Sáng/Tối (Light/Dark Mode) linh hoạt [ID:252][ID:269]. Ứng dụng được thiết kế tối giản, hiện đại, loại bỏ hoàn toàn các tính năng chuông báo phức tạp để mang lại trải nghiệm tập trung cao độ nhất [ID:252].

## ✨ Tính năng chính
- **Đồng hồ Pomodoro đa năng**: Hỗ trợ 3 chế độ đếm ngược: Pomodoro (25 phút), Nghỉ ngắn (5 phút), và Nghỉ dài (15 phút) [ID:252][ID:269].
- **Tùy chỉnh thời gian linh hoạt**: Cho phép thay đổi thời gian của từng chế độ với cơ chế kiểm tra dữ liệu đầu vào nghiêm ngặt [ID:252][ID:475].
- **Quản lý tác vụ (To-Do List)**: Thêm, sửa, xóa, đánh dấu hoàn thành tác vụ và liên kết trực tiếp với phiên làm việc [ID:252].
- **Chế độ Sáng/Tối (Light/Dark Mode)**: Chuyển đổi giao diện mượt mà, lưu trữ trạng thái lựa chọn trực tiếp vào LocalStorage [ID:252][ID:269].
- **Lưu trữ dữ liệu bền vững**: Tự động đồng bộ hóa toàn bộ cấu hình, danh sách tác vụ và lịch sử phiên làm việc vào LocalStorage [ID:269].

## 🛠️ Công nghệ sử dụng
- **Backend**: Node.js & Express (Phục vụ static files) [ID:269].
- **Frontend**: HTML5, CSS3 (Tailwind CSS & Custom Variables), Vanilla JavaScript [ID:269].
- **Testing**: Playwright (E2E Testing Suite) [ID:443][ID:475].
